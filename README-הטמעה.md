# ביכורי שילה — עמוד נחיתה (שלב א')

עמוד נחיתה עצמאי (One-pager), RTL, רספונסיבי, מוכן להטמעה באתר ה־Wix הקיים.

## קבצים
- `index.html` — מבנה ותוכן העמוד
- `styles.css` — עיצוב (צבעי המותג מהלוגו)
- `script.js` — ניווט מובייל + שליחת טופס לוואטסאפ
- `assets/images/` — תמונות מותאמות לוב (נדחסו ~53%)

## צפייה מקומית
מריצים שרת מתיקיית `site` וגולשים ל־`http://localhost:5178`:
```
py -3 -m http.server 5178 --directory site
```

## הטמעה ב־Wix (תוכנית Core — נתמך)

### אפשרות א' — Embed קוד (הכי מהיר)
1. בעורך Wix: **Add → Embed Code → Embed HTML / iframe** (או "Custom Element").
2. מכיוון ש־Wix מטמיע דרך iframe, הכי אמין להעלות את שלושת הקבצים לאחסון (למשל Netlify / GitHub Pages / כל שרת) ולהצביע ל־URL, או להדביק את ה־HTML המאוחד.
3. להגדיר את הרכיב לרוחב מלא (Full Width) וגובה מתאים.

### אפשרות ב' — לינק לעמוד ייעודי
לארח את העמוד בכתובת משנה (למשל `visit.katifshiloh.com`) ולקשר אליו מתפריט ה־Wix. יתרון: SEO מלא (לא בתוך iframe).

## ⚠️ הערת SEO
תוכן בתוך iframe מקבל פחות ערך בגוגל. מומלץ להשאיר בעמוד ה־Wix המארח כותרת H1 ותיאור עם מילות המפתח: "אירועים בשילה", "בציר בשומרון", "נופש משפחתי בבנימין".
